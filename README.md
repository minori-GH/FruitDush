# Fruit Dash

Unity・C#で個人開発した、縦画面の2Dアクションゲームです。
プレイヤーをジャンプと方向転換で操作し、フルーツを集めながら、制限時間内にスタート地点へ戻ることを目指します。

## ルールと操作方法

- プレイヤーは右方向へ自動で走り始めます。方向転換すると、反対方向へ走ります。
- フルーツに触れるとスコアが加算されます。
- 制限時間は60秒です。スタート地点から一度離れ、時間内に戻るとクリアです。
- 敵に触れると吹き飛ばされ、0.5秒間操作できなくなります。接触後は1秒間、敵に当たっても影響を受けません。
- 時間切れになるとゲームオーバーです。

| 操作 | 動作 |
| --- | --- |
| 短押しして離す（0.2秒未満） | 地面にいるときにジャンプします。 |
| 長押しして離す（0.2秒以上） | 左右の移動方向を切り替えます。 |
| Pauseボタン | ゲームを一時停止します。Resumeボタンで再開できます。 |

タッチ操作とマウスクリックに対応しています。時間などの数値は公開コードの初期設定です。

## ゲームの流れ

1. Startボタンを押すと、移動とカウントダウンが始まります。
2. 敵を避けながらフルーツを集め、方向転換してスタート地点へ戻ります。
3. クリア画面では今回のスコアとベストスコアを表示し、記録を更新すると「NEW RECORD」を表示します。
4. ゲームオーバー時は、リワード広告の報酬を獲得し、広告を閉じると10秒追加して続けられます。この復帰は1プレイにつき1回です。
5. Retryボタンを押すと最初の画面へ戻ります。ポーズ・ゲームオーバー・クリア画面のRetry回数を共通で数え、10回ごとに全画面広告の表示を試みます。広告が表示される場合は、閉じてから戻ります。

## 主な実装機能

| 機能 | 内容 |
| --- | --- |
| プレイヤー操作 | オートラン、短押しジャンプ、長押し後の方向転換、敵に触れたときの吹き飛びと操作停止を実装しています。 |
| ゲーム進行・時間管理 | 開始、プレイ中、ポーズ、ゲームオーバー、クリアを管理し、プレイ中だけ残り時間を減らします。 |
| スコア | フルーツごとの得点加算、取得位置での「+スコア」表示、クリア時のベストスコア保存に対応しています。 |
| 敵・カメラ | 敵の左右往復移動と、プレイヤーの進行方向の少し前を映すカメラ追従を実装しています。 |
| UI演出 | 残り30秒で時計を一瞬拡大し、残り5秒からカウントダウンを表示します。 |
| 広告 | AdMobの全画面広告と、10秒追加用のリワード広告を組み込んでいます。iOS・Android用の広告IDを切り替えます。 |
| アニメーション・音・文字表示 | 移動・空中・被弾に応じたアニメーション、効果音の再生と言語に応じたフォント切り替えに対応しています。 |

| [EnemyMove.cs](Scripts/EnemyMove.cs) | 敵を初期位置から左右に往復移動させます。 |
| [EnemyContact.cs](Scripts/EnemyContact.cs) | 敵との接触をPlayerControllerへ伝えます。 |
| [FruitItem.cs](Scripts/FruitItem.cs) | フルーツ取得時に得点を加算し、効果音とスコア表示を呼び出します。 |
| [ScorePopup.cs](Scripts/ScorePopup.cs) | 「+スコア」を上へ動かし、一定時間後に消します。 |
| [StartGoalTrigger.cs](Scripts/StartGoalTrigger.cs) | スタート地点から離れた後、戻ってきたことを判定します。 |
| [UIManager.cs](Scripts/UIManager.cs) | 画面の切り替え、時間・スコアの表示、各ボタンの処理を担当します。 |
| [TimeUIEffectController.cs](Scripts/TimeUIEffectController.cs) | 残り時間に応じた時計とカウントダウンの演出を担当します。 |
| [ResultBestScoreUI.cs](Scripts/ResultBestScoreUI.cs) | クリア時にベストスコアを保存し、記録更新を表示します。 |
| [AudioManager.cs](Scripts/AudioManager.cs) | 効果音の再生と、音ごとの音量を管理します。 |
| [LocalizedTMPFontSwitcher.cs](Scripts/LocalizedTMPFontSwitcher.cs) | 言語の変更に合わせて、対象テキストのフォントを切り替えます。 |
| [AdManager.cs](Scripts/AdManager.cs) | 広告の読み込み、表示、終了後の処理を担当します。クラス名はAdMobManagerです。 |
